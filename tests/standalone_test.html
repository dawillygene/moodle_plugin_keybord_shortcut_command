Keyboard Shortcuts Plugin - Test Environment

This page simulates the Moodle environment to test keyboard shortcuts functionality.

Available Keyboard Shortcuts

  • Alt + H - Go to Home
  • Alt + D - Go to Dashboard
  • Alt + C - Go to Courses
  • Alt + P - Go to Profile
  • Alt + S - Open Search
  • Alt + L - Logout
  • Alt + ? - Show Help
  • Esc - Close Help
